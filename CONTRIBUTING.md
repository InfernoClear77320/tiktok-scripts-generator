# Contributing

Thanks for helping improve TikTok Scripts Generator!

## Before opening a pull request
- Keep the interface simple and accessible.
- Never commit API keys, tokens, or personal data.
- Test the app locally and run the unit tests.
- Keep generated scripts clearly separated from production notes.
- Avoid claims that guarantee virality, views, income, or health outcomes.

## Pull requests
Describe the user-facing change, include steps to test it, and add screenshots for meaningful UI changes where useful.

## Reporting issues
Include your Python version, operating system, steps to reproduce, and the full error message. Remove secrets and personal data first.
